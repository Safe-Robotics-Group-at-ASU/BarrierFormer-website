Project website for **BarrierFormer: Transformer-Guided Predictive Barrier Enforcement for Safe Robot Control** (CoRL 2026), live at [safe-robotics-group-at-asu.github.io/BarrierFormer-website](https://safe-robotics-group-at-asu.github.io/BarrierFormer-website/).

Put figures in `figs/`, videos in `vids/`, and the paper PDF in `files/`; replacing a file with the same name updates the page with no HTML edits. Videos play only while scrolled into view, so any new `<video>` needs `data-autoplay-on-view` rather than an `autoplay` attribute. Search `index.html` for `TO RELEASE` to switch the Paper, arXiv and Code buttons on once those are public.

This template is originally based on the [Nerfies website](https://github.com/nerfies/nerfies.github.io) and subsequent [website](https://realm-locus-ral-icra-22.github.io) in the REALM lab.
